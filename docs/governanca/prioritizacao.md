# Priorização VRUE — Valor, Redução de Risco, Urgência, Esforço

Score = (V + R + U) / E

- V (Valor): 1=baixo benefício, 5=alto impacto para metas
- R (Redução de Risco): 1=marginal, 5=elimina risco relevante (segurança, dados, operação)
- U (Urgência): 1=pode esperar, 5=janela imediata/compliance/prazo externo
- E (Esforço): 1=muito baixo, 5=alto (pessoas-semana)

Classes:
- Alta: score ≥ 2.5
- Média: 1.6–2.49
- Baixa: < 1.6

Exemplo:
- Segurança básica (V=4, R=5, U=4, E=3) → (4+5+4)/3 = 4.33 (Alta)
- Refino visual menor (V=2, R=1, U=2, E=2) → 2.5 (Alta limítrofe)

Usar sempre justificativa curta ao lado do score.
